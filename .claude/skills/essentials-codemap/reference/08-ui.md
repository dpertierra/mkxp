# Reference · UI (controles, pantallas y UI no interactiva)

Carpetas: `047_UI Elements`, `048_UI`, `049_Non-interactive UI`. Conviven dos generaciones de UI: el patrón clásico `PokemonX_Scene`+`PokemonXScreen` y el framework moderno `UI::` (`048/000_UI_base.rb`) con controles MUI. Para diseñar pantallas ver skill `game-ui-design`; para opciones/menús ver `menu-and-options`.

## 047_UI Elements
Sistema de **controles MUI** (widgets reutilizables tipo formulario).

### 001_UIControls.rb
- **Core:** base del sistema de controles MUI.
- **Encontrarás:** la infraestructura común de los widgets (eventos, dibujo, foco).
- **Consulta si:** entender el framework de controles.

### 002_ControlsContainer.rb
- **Core:** contenedor que agrupa y gestiona varios controles.
- **Encontrarás:** layout, navegación entre controles y propagación de input.
- **Consulta si:** montar un panel con varios widgets.

### ControlElements/
Un archivo por widget. **Consulta si:** necesitas ese control concreto en una pantalla.
- **001_BaseControl.rb** — clase base de todos los controles.
- **002_Label.rb** — etiqueta de texto.
- **003_Checkbox.rb** — casilla on/off.
- **004_TextBox.rb** — campo de texto.
- **005_NumberSlider.rb** — deslizador numérico.
- **006_NumberTextBox.rb** — campo numérico.
- **007_Button.rb** — botón de texto.
- **008_BitmapButton.rb** — botón con imagen.
- **009_List.rb** — lista seleccionable.
- **010_DropDownList.rb** — desplegable.
- **011_TextBoxDropDownList.rb** — desplegable con búsqueda por texto.
- **012_Scrollbar.rb** — barra de scroll.

## 048_UI
**Todas las pantallas interactivas** del juego. Marcadas **(custom)** las añadidas por La Base de Sky/terceros.

### 000_UI_base.rb
- **Core:** **framework base de UI moderno** (`UI::`): visuals, scenes, contenedores de sprites.
- **Encontrarás:** las clases base sobre las que se construyen las pantallas nuevas (BaseVisuals, contenedores, mixins).
- **Consulta si:** crear una pantalla con el framework moderno (ver skill `game-ui-design`).

### 002_UI_PauseMenu.rb
- **Core:** menú de pausa (botón Start).
- **Encontrarás:** la pantalla del menú principal y sus comandos (registrados vía `MenuHandlers`).
- **Consulta si:** añadir/editar una opción del menú de pausa (ver skill `menu-and-options`).

### 002_Pokegear Themes/
Subsistema de Pokégear con temas. **Consulta si:** la interfaz del Pokégear, sus temas o el reloj/teléfono integrados.
- **002_Pokegear_Config.rb** — configuración del Pokégear (espaciados, opciones).
- **003_Pokegear_Main.rb** — pantalla principal del Pokégear.
- **004_Pokegear_Themes.rb** — definición/aplicación de temas visuales.
- **005_FL's Pokegear Watch addon.rb** — **(custom)** addon de reloj.
- **006_Pokegear_Phone.rb** — vista de teléfono dentro del Pokégear.
- **007_Pokegear_RegionMap.rb** — mapa de región dentro del Pokégear.
- **008_Pokegear_ThemeButton.rb** — botón de selección de tema.
- **009_Pokegear_ThemeOptions.rb** — opciones de tema.

### 003_Box Auto-Sort/
**(custom)** Ordenado automático de cajas del PC. **Consulta si:** ordenar/auto-organizar el almacenamiento.
- **002_Settings.rb** — ajustes del auto-sort.
- **003_SortAlgorithms.rb** — algoritmos de ordenación (por dex, tipo, nivel…).
- **004_BoxIntegration.rb** — integración con la UI del PC.
- **005_Event_Handler.rb** — handlers que enganchan el auto-sort.

## 049_Non-interactive UI
Secuencias visuales sin (o con poca) interacción del jugador.

### 002_UI_SplashesAndTitleScreen.rb
- **Core:** splashes iniciales y pantalla de título.
- **Encontrarás:** los logos de arranque y el título.
- **Consulta si:** editar el arranque visual o el título.

### 003_UI_Controls.rb
- **Core:** controles/elementos auxiliares de estas secuencias.
- **Encontrarás:** widgets compartidos por las pantallas no interactivas.
- **Consulta si:** elementos comunes de estas escenas.

### 004_UI_EggHatching.rb
- **Core:** eclosión de huevos.
- **Encontrarás:** la animación de romper el huevo.
- **Consulta si:** la secuencia de eclosión.

### 005_UI_Evolution.rb
- **Core:** escena de evolución.
- **Encontrarás:** la animación y el flujo de evolucionar (cancelable).
- **Consulta si:** la pantalla de evolución (disparada desde `043`/combate).

### 006_UI_Trading.rb
- **Core:** escena de intercambio.
- **Encontrarás:** la animación de trade y la evolución por intercambio.
- **Consulta si:** la secuencia de intercambio.

### 007_UI_HallOfFame.rb
- **Core:** Salón de la Fama.
- **Encontrarás:** el registro y la presentación del equipo campeón.
- **Consulta si:** entrar/mostrar el Hall of Fame.

### 008_UI_Credits.rb
- **Core:** créditos.
- **Encontrarás:** el desplazamiento de créditos.
- **Consulta si:** editar/mostrar los créditos.

### 009_Species Introduction.rb
- **Core:** **(custom)** presentación de una especie (estilo "ficha de introducción").
- **Encontrarás:** la imagen+texto que presenta una especie con su grito.
- **Consulta si:** mostrar una intro de especie.
